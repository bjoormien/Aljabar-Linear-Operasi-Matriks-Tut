# Aljabar-Linear-Operasi-Matriks-Tut
Website kalkulator matriks untuk melakukan operasi penjumlahan, pengurangan, perkalian, transpose, determinan, dan invers matriks, dilengkapi dengan langkah-langkah perhitungan untuk membantu memahami konsep Aljabar Linier. 

# Matrix Calculator and Visualizer

Website kalkulator matriks yang dikembangkan untuk menerapkan konsep Aljabar Linier, khususnya operasi-operasi dasar matriks. Website ini memungkinkan pengguna melakukan perhitungan matriks sekaligus melihat proses penyelesaian dari setiap operasi yang dilakukan.

Project ini dibuat sebagai pemenuhan tugas Project Akhir mata kuliah Aljabar Linier.

## Tujuan

- Menerapkan konsep Aljabar Linier ke dalam aplikasi berbasis web.
- Mempermudah perhitungan berbagai operasi matriks.
- Menampilkan proses perhitungan agar hasil yang diperoleh dapat dipahami.
- Menghubungkan konsep matematika dengan implementasi dalam pemrograman.

## Fitur

Beberapa fitur yang direncanakan dalam website ini:

1. **Penjumlahan Matriks**  
   Menjumlahkan dua matriks dengan ordo yang sama.

2. **Pengurangan Matriks**  
   Menghitung selisih antara dua matriks dengan ordo yang sama.

3. **Perkalian Matriks**  
   Mengalikan dua matriks berdasarkan aturan perkalian baris dan kolom.

4. **Transpose Matriks**  
   Mengubah posisi baris menjadi kolom dan kolom menjadi baris.

5. **Determinan Matriks**  
   Menghitung nilai determinan dari suatu matriks persegi.

6. **Invers Matriks**  
   Menentukan invers dari matriks persegi yang memiliki determinan tidak sama dengan nol.

7. **Langkah Perhitungan**  
   Menampilkan tahapan penyelesaian dari operasi matriks yang dilakukan.

## Konsep Aljabar Linier

Konsep yang diterapkan dalam project ini meliputi:

- Matriks dan ordo matriks.
- Penjumlahan dan pengurangan matriks.
- Perkalian matriks.
- Transpose matriks.
- Determinan matriks.
- Invers matriks.
